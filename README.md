# Lens Modeling Project

This was a project for the Gravitational Lensing class offered at Stony Brook University. The objectives were:

- Familiarize myself with astronomical imaging data products;
- Learn how to reconstruct the lensing distortions from a given observed image;
- Perform posterior inference for meaningful statistical interpretations.

The final product of this project is a Jupyter notebook presenting the modeling of a real lens observed by the Hubble Space Telescope. This Jupyter notebook's path is `/model/model.ipynb`.

You can find more specific details about the assignment under `assignment-description.md`.

Tutorials were used to learn more about the project. All tutorials used are under the folders `/tutorials/`.
